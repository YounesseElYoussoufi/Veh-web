# 🎬 VEH – Plateforme Web de Création de Scénarios

## 🧠 Description du Projet

**VEH** est la partie web d’un projet d’innovation visant à offrir aux **scénaristes** un espace interactif pour **créer, visualiser et manipuler leurs scénarios** dans un environnement 3D immersif.  
Développée avec **Three.js**, cette plateforme propose une interface intuitive permettant d’explorer visuellement les éléments d’un scénario (personnages, scènes, interactions, etc.) sous forme d’univers virtuel.

[👉 Voir la démo sur YouTube](https://www.youtube.com/watch?v=6AYFclK10x0)

---

## 🚀 Fonctionnalités principales

- 🧩 **Création de scénario interactif** : les scénaristes peuvent créer, nommer et structurer leurs scénarios.
- 🎭 **Visualisation 3D avec Three.js** : représentation spatiale des scènes et transitions.
- 🪄 **Navigation immersive** : caméra libre, zoom, rotation et déplacement dans la scène.
- 💡 **Interface intuitive** : intégration de contrôles simples pour ajouter ou modifier les éléments.
- 🧱 **Gestion dynamique** : ajout d’objets, de textes ou d’animations 3D.
- 💾 **Sauvegarde / Chargement** : possibilité d’enregistrer le scénario ou de recharger une version précédente (selon les futures itérations).

## 🛠️ Technologies utilisées

| Technologie | Rôle |
|--------------|------|
| **Three.js** | Rendu 3D, animations et scène virtuelle |

| **JavaScript (ES6)** | Logique applicative et interaction utilisateur |
| **GLTF / OBJ** | Format des modèles 3D utilisés (si applicable) |
| **Vite / Webpack** | Compilation et gestion du projet web |
| **GitHub Pages / Vercel** | Déploiement de la version web (optionnel) |
